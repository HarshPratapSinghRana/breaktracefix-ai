# Contributing to BreakTraceFix AI

Thank you for your interest in contributing to BreakTraceFix AI.

## Development Workflow
1. Fork the repository and create a feature branch (`feat/your-feature-name`).
2. Run backend test suites: `python -m pytest tests -v`.
3. Verify frontend production compilation: `cd frontend && npm run build`.
4. Ensure all new attack scenarios or policies implement defense invariants.
5. Open a Pull Request detailing the technical changes and test results.
