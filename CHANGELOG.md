# Changelog

All notable changes to BreakTraceFix AI are documented in this file.

## [1.0.0] - 2026-11-24
### Initial Production Release
- **Core Engine 1**: Attack Simulation Engine with 14 built-in threat vectors.
- **Core Engine 2**: 8-Axis Context-Aware Authorization Intelligence Engine.
- **Core Engine 3**: 11-Stage Data Flow & Execution Tracing with automated redaction.
- **Core Engine 4**: Vulnerability Reproduction & Patch Validation Workbench.
- **Core Engine 5**: Semgrep-powered Source Code Security Analyzer & SARIF 2.1.0 engine.
- **Core Engine 6**: Multi-Format Security Reporting Engine (JSON, HTML, SARIF).
- **Advanced Features**: MCP Security Inspector, RAG Security Auditor, AI Permission Risk Scoring.
- **Frontend Dashboard**: 12 operational views built with React 18, TypeScript, Vite, and Tailwind CSS.
- **Deployment**: Dual deployment architecture supporting Vercel Serverless and Docker Compose.
