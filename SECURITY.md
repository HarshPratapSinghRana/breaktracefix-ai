# Security Policy

## Reporting Security Vulnerabilities
BreakTraceFix AI is a security research and runtime defense platform. If you discover a vulnerability in BreakTraceFix AI itself, please report it privately:

- **Contact**: security@breaktracefix.ai
- **Author**: Harsh Pratap Singh Rana
- **Response SLA**: 48 hours for triage and verification.

Please do not open public GitHub issues for undisclosed security vulnerabilities.
